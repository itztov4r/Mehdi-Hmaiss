Les fichiers images d'Unsplash sont appelés depuis `images.unsplash.com` à l'affichage. Une connexion Internet est donc nécessaire pour voir les photographies. Si une image distante ne peut pas être chargée, un **visuel SVG local original**, présent dans le dossier `assets/illustrations/`, est affiché automatiquement. Le site reste entièrement fonctionnel même hors ligne.

## Autres médias

- `assets/workspace.jpg` et `assets/cv-mehdi-hmaiss.pdf` proviennent du portfolio fourni par l’utilisateur. Le nouveau logo original `assets/branding/mh-logo.svg` et ses variantes ont été créés pour cette édition V4.
- `assets/illustrations/*.svg` : visuels vectoriels créés spécifiquement pour cette version. Les illustrations de projets sont des maquettes, non des captures réelles.
- Les captures dans `previews/` illustrent l'interface du portfolio. Les images Unsplash ne sont pas chargées pendant les captures locales de test ; leurs remplacements SVG sont visibles.

## Remplacer une photographie

Dans `index.html`, recherchez `images.unsplash.com/photo-...` pour changer les URLs. Les couvertures SVG utilisées hors ligne peuvent aussi être modifiées dans `assets/illustrations/`.
